Project Overview

This is a test automation framework that caters to functionality around UI (both desktop web and mobile) as well as API testing for both REST and SOAP services.

click to view project source.

Tech Stack

Programming Language

  • Java: Core language used for developing the framework and demo test scripts.

Test Automation Frameworks:

  • Selenium WebDriver: To automate UI tests on desktop web applications.

  • Appium: To automate mobile applications.

  • JUnit5: To structure and execute tests.

API Testing Tools:

  • RestAssured: To validate both REST and SOAP API endpoints and services.

CI/CD & Version Control:

  • Jenkins: Integrated into the framework to automate build processes, test execution, and continuous integration.

  • Git & GitHub: For source code management and version control, ensuring seamless integration with the CI/CD pipeline.

Build Tool:

  • Maven: To manage project dependencies, building, and packaging the automation project.

Logging & Reporting:

  • Logback: To efficiently log and track test execution, errors, and monitor the system's behavior.

  • Log4j2: As the logging implementation for the Logback facade.

  • ExtentReports: For generating detailed, interactive, and customizable test reports to summarize the results of executed tests.

Encryption & Decryption:

  • Cipher: Used for secure encryption and decryption of sensitive data within the test automation processes.
